# Aether Current Navigator

[English](README.md)

フィールド風脈と風脈クエストを、進捗一覧とマップから確認・処理するDalamud API 15向けプラグインです。

- 作者: `Roxyz0501`
- ライセンス: `AGPL-3.0-only`。詳細は[LICENSE](LICENSE)と[NOTICE.md](NOTICE.md)を参照してください。
- コマンド: `/acnav`

## 主な機能

- 蒼天から黄金まで、拡張・エリア別にフィールド風脈と風脈クエストの進捗を表示します。
- ゲーム内マップへフィールド風脈とエーテライト候補を重ね、マップ画像がない場合は座標グリッドを表示します。
- 現在エリア、指定拡張、または一覧で選んだ風脈・クエスト1件を処理します。拡張実行は1エリアを終えてから次へ進みます。
- 現在地と各エーテライトからの経路を比較し、通常テレポのほうが短い場合はテレポしてから移動します。
- vnavmeshの飛行なし地上経路を使い、急激な上下移動を含む飛行前提と思われる経路を除外します。
- 現在地点からの通路再計算とスタック検出に対応し、スタック時は未使用のエーテライトへ切り替えます。全候補で失敗した場合は停止します。
- テレポ完了後に設定したマウントへ騎乗し、移動を止めず最大10回再試行します。水泳後に騎乗可能になった場合も再騎乗します。
- 受注後のクエスト処理はQuestionableの公開IPCへ引き渡します。
- UI、状態、エラー、ツールチップ、依存関係、支援画面を英語・日本語で表示できます。

ゲーム標準のテレポ、移動、騎乗、ターゲット、インタラクト処理のみを使用します。座標変更や不正なワープは行いません。

## インストール

Roxyz0501が管理する共通Dalamudカスタムリポジトリからの配布を予定しています。

1. 最終URLの公開後、Dalamudのカスタムプラグインリポジトリへ `__SHARED_CUSTOM_REPOSITORY_URL__` を追加します。
2. Dalamudのプラグインインストーラーを開きます。
3. **Aether Current Navigator**をインストールします。
4. 下記の依存プラグインを導入して読み込みます。

`__SHARED_CUSTOM_REPOSITORY_URL__` は未確定URLを示すプレースホルダーであり、そのままでは利用できません。

## 利用方法

`/acnav`またはDalamudプラグイン一覧のボタンから画面を開きます。

- **現在のフィールドを解放**: 現在エリアで有効にした対象を処理します。
- **指定拡張をすべて解放**: 選択した拡張をエリア単位で処理します。
- 各風脈・クエスト横の再生ボタン: その1件だけを処理します。
- **通路を再計算**: 現在の経路を破棄し、ボタンを押した地点から再探索します。
- 停止・一時停止ボタン: 現在のフェーズで可能な場合に実行を制御します。
- 風脈マップ: フィールド風脈、現在の対象、通常エーテライト候補を表示します。
- 状態: 直接・間接依存プラグインの読み込み状態を表示します。

## コマンド

- `/acnav` — メイン画面を開きます。
- `/acnav stop` — 本プラグインが開始した自動処理を停止します。

## 設定と言語

設定画面では、処理対象、拡張実行前の確認、移動用マウント、デバッグ情報、表示言語を設定できます。

初回起動時だけDalamud／ゲームクライアント言語を検出します。日本語クライアントでは**日本語**、それ以外または検出不能時は**English**を選択してConfigへ保存します。初期化後は起動時に再検出せず、保存済みの言語を維持します。ユーザーが**English**または**日本語**へ変更した場合も、その値を以後そのまま使用します。

処理対象とマウントは、ゲームのコンテンツIDをキーにキャラクター別で保存します。表示言語はプラグイン全体の設定です。移動マウントの初期値はマウント・ルーレットで、所持済みマウントも選択できます。

## 必要な依存プラグイン

- **vnavmesh** — フィールド移動と経路選択に必須です。
- **Questionable** — 風脈クエストに必須です。フィールド風脈だけを使う場合は任意です。
- **TextAdvance** — Questionableが必要とする間接依存です。
- **Lifestream** — Questionableが必要とする間接依存です。

本プラグインは依存プラグインの設定を変更したままにしません。

## データとプライバシー

- 設定はDalamudのプラグイン設定領域へ保存します。
- キャラクター別設定を分けるため、ゲームのコンテンツIDを保存します。
- キャラクター名、座標履歴、経路履歴、APIキー、認証情報は保存しません。
- テレメトリー送信や外部Web APIへの自動通信は行いません。
- ゲーム内処理は、インストール済みプラグインとローカルDalamud IPCで通信します。
- 支援タブは、ユーザーがボタンを押した場合だけ `https://ko-fi.com/roxyz0501` を開きます。

## 既知の制限

- 到達可能性はvnavmeshのナビメッシュと現在のゲーム地形に依存します。
- NPC移動や特殊な進入条件を移動前に完全判定できない場合があります。
- 引き渡し後のクエスト処理はQuestionableの対応経路と設定に依存します。
- 通常テレポ代が発生します。テレポ失敗または到着未確認時は自動処理を停止します。
- ゲーム、Dalamud、依存プラグイン、QuestPathsの更新後はデータ更新と実機再確認が必要になる場合があります。

## トラブルシューティング

- **移動しない:** 状態タブでvnavmeshが読み込み済み・使用可能か確認してください。
- **クエストが始まらない:** Questionableと間接依存を確認し、一覧に表示されるクエスト条件を確認してください。
- **経路失敗を繰り返す:** 移動中に通路を再計算してください。その後もスタックした場合は未使用エーテライトへ切り替え、全候補失敗時は停止します。
- **マップ画像がない:** 座標グリッド表示は利用できます。デバッグ情報を有効にしてマップ／エーテライト診断を確認してください。
- **表示言語が違う:** 設定でEnglishまたは日本語を選択してください。自動検出は言語値を初めて保存する前だけ実行されます。
